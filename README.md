predictive-maintenance


Can We predict when a part will fail?

I want to be able to predict how long till an engine will fail based on sensor readings.

You can find the the dataset I used for this project at [**this link**](https://phm-datasets.s3.amazonaws.com/NASA/6.+Turbofan+Engine+Degradation+Simulation+Data+Set.zip). Of the 4 potential datasets, I used FD003 dataset.
